## Addressing Relevant Implications

### ACCESSIBILITY

To ensure that my web app was Accessible for my users and met the requirements I set based on the implications of the design, I;
 - Tested and confirmed that the web app works on a range of different devices: computers, mobile devices, e.c.t. Allowing users with any device to access and use the site.
 - Designed UI and web app functionality to be as clear and straightforward as possible. Aiming for no confusion for users when utilizing the web app.
 - Checked that Elements are tagged correctly and are fully accessible so that any user can use the web app fully.
 - Ensured that my UI looks good, is well contrasted and all text is readable, so that no visual or UX issues occur

Overall through testing and iterating my system I was able to make it more accessible to my users, and improve the way the system interacted with my users.


### PRIVACY

To ensure that my web app met the Privacy for my users I set based on the implications of the system, I;
 - Made sure that the system only collected important data for the function of the system to not cause unnecessary privacy issues.
 - Created routes such that data like passwords is stored securely in hash form to ensure that any possible database leaks do not give anyone direct unencrypted access to private information.
 - Users intentionally and consensually create passwords to sign up and vote and no other data is collected in secret from them.
 - Designing the system so that profiles can only be only be viewed by the owner (except creator profiles which are public) but no data that could cause privacy issues can be accessed by anyone else.

Overall through testing of my system I minimized and possible privacy breaches or issues as much as I could and overall improved the security of the system for my users.
